# Info

HTML tags:
html tags are what make up the majority of the website pages. They control the size and style of the text. Whatever is placed between the beginning tag and end tag is affected by style. 
Some common one are:
- <h1><h1/>
- <h2><h2/>
- <h3><h3/>
- <p></p>

<h1>, <h2>, and <h3> are all different sized headings. <p> is probably going to be the most important tag. To change the text of different pages, simply change the text between the <p> tags.
