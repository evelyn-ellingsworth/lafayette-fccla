# Info

HTML tags:
html tags are what make up the majority of the website pages. They control the size and style of the text. Whatever is placed between the beginning tag "<" and end tag "/>" is affected by style. 
Some common one are:
- h1
- h2
- h3
- p

h1, h2, and h3 are all different sized headings. p is probably going to be the most important tag. To change the text of different pages, simply change the text between the tags.

Embedding Canva slides and PDFs:
For Canva you have to be an editor or owner of the slides. Then go to share and choose the embed code for html. It is marked on the pages what code to replace. For PDFs, go to the file options and click share. Choose to get the embed link. You will only need what is in between the https and preview. There is more details on the pages with PDFs.
