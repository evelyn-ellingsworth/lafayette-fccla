# Info

<h2>HTML tags:</h2> 
<br>
<p>html tags are what make up the majority of the website pages. They control the size and style of the text. Whatever is placed between the beginning tag "<" and end tag "/>" is affected by style. 
Some common one are:</p>
<p>- h1</p>
<p>- h2</p>
<p>- h3</p>
<p>- p</p>

<p>h1, h2, and h3 are all different sized headings. p is probably going to be the most important tag. To change the text of different pages, simply change the text between the tags.</p>

<h2>Embedding Canva slides and PDFs: </h2>
<br>
For Canva you have to be an editor or owner of the slides. Then go to share and choose the embed code for html. It is marked on the pages what code to replace. For PDFs, go to the file options and click share. Choose to get the embed link. You will only need what is in between the https and preview. There is more details on the pages with PDFs.

<h2>Images:</h2>
<br>
<p>To add new images to the pages, you first have to add it to the repository on GitHub. Follow these steps to do this:</p>
<p>- First make sure that the image is saved on your computer</p>
<p>- Change the name of the file and/or make it a jpg or png. The name of the file is the name you will have to use in GitHub so make it easy to understand!</p>
<p>- Then go to the image folder, it is under "assests</p>
<p>- Click on the "add file" button in the top right corner</p>
<p>- Click upload file</p>
<p>- Click the blue text that says "choose your files" and select the image(s) that you want to upload</p>
<p>- hit the green commit changes button</p>
